# Imágenes del Blog — Notas de Explorador

Aquí puedes almacenar imágenes locales de dinosaurios y guías.

## Cómo usar

1. Coloca tus imágenes en esta carpeta (PNG, JPG, WebP recomendados).
2. Referencia en tus posts así:
   ```markdown
   ![Descripción de la imagen](/myblog2/assets/images/nombre-imagen.png)
   ```

## Imágenes sugeridas a descargar

- `raptor.png` — Raptor de ARK (para post de Raptor)
- `brontosaurus.png` — Brontosaurus de ARK (para post de Brontosaurus)
- `trike.png` — Triceratops (para futuras fichas)
- `t-rex.png` — T-Rex (para futuras fichas)

### Fuentes recomendadas
